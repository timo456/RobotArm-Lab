# Third-party sources and licenses

No third-party robot mesh, URDF, texture, CAD or dataset is bundled. The original RAL-6
model is generated by `scripts/generate_model.py`; project code/model/media use MIT.
Dependencies are installed separately and retain their accompanying licenses/notices.

Version 0.1.1 adds no runtime third-party package. Its wrist-center geometry and
branch enumeration are original project code using the existing SciPy rotation and
optimization APIs. Windows working-set measurement uses Python's standard-library
ctypes with the operating-system API. Cached PyBullet wheel provenance and exact
dependency-wheel hashes are recorded under `reports/v0.1.1/wheelhouse.json`; binaries
and build caches are excluded from Git and the source archive.

Technical references (APIs and algorithms, no copied model assets):

- [Official PyBullet quickstart](https://github.com/bulletphysics/bullet3/blob/master/docs/pybullet_quickstart_guide/PyBulletQuickstartGuide.md.html):
  DIRECT clients, link frame vs COM frame, closest-point queries and TinyRenderer.
- [SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html):
  bounded trust-region nonlinear least squares.
- [SciPy Rotation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.transform.Rotation.html):
  SO(3) representations and rotation vectors.
- [PyBullet distribution files](https://pypi.org/project/pybullet/3.2.7/#files):
  official source distribution and platform wheels.

FK and quintic timing equations are implemented explicitly in this repository.

## v0.2.0 Qt workstation

The procedural lathe/box meshes, bolts, housings, tool, materials, shader source,
table, grid and captured workstation media are original project work under MIT.
There are no downloaded CAD models, textures, fonts or AI-generated screenshots.
PyOpenGL was evaluated during development and removed; it is not a runtime dependency.

The Python application dynamically imports the separately installed Qt libraries.
No Qt library is modified, statically linked, embedded in our project wheel or
placed in a locked executable. You may replace/rebuild the Qt/PySide libraries,
modify this application and reverse engineer it for debugging those modifications.
There is no installation signature check or technical restriction on replacement.
To use modified compatible wheels, install them into a separate environment with
`python -m pip install --no-deps --force-reinstall path/to/modified.whl`, then
install this project's wheel with `--no-deps`. The ordinary reproducible installer
pins upstream versions; it is not required for running a modified installation.
